# Прототип книжного рекомендательного сервиса (Goodbooks-10k)

Домашнее задание «Рекомендательные системы»: реализовать, проанализировать и сравнить Popularity, контентную модель (TF-IDF), Item-based CF и SVD,
оценить их метриками Precision@K / Recall@K / nDCG@K и предложить гибрид против холодного старта.

**Основной файл — [`goodbooks_recsys.ipynb`](goodbooks_recsys.ipynb)** (ноутбук уже выполнен: все таблицы и графики сохранены в нём).

## Структура репозитория

```
.
├── goodbooks_recsys.ipynb   # решение: EDA → модели → оценка → гибрид → выводы
├── README.md                # этот файл
├── requirements.txt         # зависимости
└── data/                    # CSV датасета Goodbooks-10k (books, ratings, tags, book_tags)
```

Датасет: <https://www.kaggle.com/zygmunt/goodbooks-10k>. Архив нужно распаковать в папку `data/` (ноутбук ищет `data/`, `./`, `../data/`).
Файлы `to_read.csv` и `sample_book.xml` из архива в работе не используются (`to_read` упомянут в идеях улучшения).

## Как запустить

```bash
pip install -r requirements.txt
jupyter lab goodbooks_recsys.ipynb      # Run All
```

* Полный прогон ≈ 8–10 минут, памяти нужно порядка нескольких ГБ (плотная матрица сходств 10 000 × 10 000 float32 ≈ 400 МБ + чанки оценок). Все случайные процессы зафиксированы (`SEED = 42`), повторные прогоны дают одинаковые числа.
* Протестировано на Python 3.13, pandas 2.3, scikit-learn 1.7, scikit-surprise 1.1.5.

## Логика решения

| Этап | Что сделано |
|---|---|
| **1. EDA** | Распределение оценок (смещение к 4–5), активность пользователей (график «пользователи vs число оценок», сегменты, холодный старт), популярность книг (длинный хвост, кривая Лоренца), топ тегов (с очисткой служебных «полок»), разреженность 99.82 %, таблица и ответ о проблемах данных |
| **Подготовка** | Per-user hold-out 80/20 (в данных нет timestamp), дополнительный `train_inner/val` для подбора гиперпараметров; разреженные CSR-матрицы; метрики P/R/nDCG@K с юнит-тестом на ручном примере; единый интерфейс `Recommender`, оценка по чанкам пользователей |
| **2. Бейзлайны** | `popular_books()` — среднее с порогом ≥ 50 оценок (обоснование через стандартную ошибку); контентная модель: профиль = название + топ-20 тегов (с весами по `count`), TF-IDF, `get_similar_books(book_id, N=5)`, проверка по совпадению автора |
| **3. Item-based CF** | Косинус / adjusted cosine + shrinkage на разреженных матрицах, блочный расчёт, top-K соседи; `ItemCFRatingPredictor` (формула из задания и улучшенная baseline-adjusted версия со «сжатием»); **ответ о сложности** и эмпирический замер |
| **4. SVD** | `surprise.SVD` с подбором гиперпараметров на validation, RMSE на test, **векторная** `get_recommendations(user_id, N=5)` (проверена на совпадение с `algo.predict`), доп. эксперимент PureSVD |
| **5. Оценка** | Все модели на отложенной выборке: сводная таблица P/R/nDCG @5/10/20, 95 % ДИ, покрытие каталога, негативный контроль утечки |
| **6. Гибрид и выводы** | Бленд Item-CF + Content + SVD (веса на validation), слоты для новинок, откат к Popularity для новых пользователей; эксперимент «холодные книги»; выводы, сильные/слабые стороны, идеи улучшения |

## Ключевые результаты (test, 42 523 пользователя, K = 10)

| Модель | Precision@10 | Recall@10 | nDCG@10 | RMSE |
|---|---|---|---|---|
| Random | 0.0003 | 0.0011 | 0.0006 | – |
| Popularity (среднее с порогом) | 0.0004 | 0.0018 | 0.0010 | – |
| Content-based (TF-IDF) | 0.0367 | 0.1586 | 0.1167 | – |
| **Item-based CF** | 0.0724 | 0.2720 | 0.2174 | 0.799 (baseline-adjusted + сжатие) |
| SVD (surprise) | 0.0006 | 0.0018 | 0.0011 | 0.830 |
| PureSVD (неявные данные, доп.) | 0.0602 | 0.1830 | 0.1432 | – |
| **Hybrid** | **0.0734** | **0.2768** | **0.2224** | – |

**Главное:**
* **Item-based CF — лучшая одиночная модель для Top-N**, а гибрид даёт небольшой, но статистически значимый прирост (nDCG@10 +0.005 ± 0.001) и умеет рекомендовать новые книги.
* **SVD точен по RMSE, но бесполезен как ранжировщик Top-N** (обучается на оценках уже прочитанных книг и не знает, что пользователь выбирает; MNAR). Та же факторизация по факту взаимодействия (PureSVD) уже работает (nDCG@10 0.143).
* **Popularity ≈ Random**: в `ratings.csv` на книгу приходится ≈ 100 оценок, популярность в выборке «сплющена»; бейзлайн остаётся запасным вариантом для пользователя без истории.
* **Холодные книги:** контентная модель находит ≈ 31 % релевантных новинок в Top-10 (Item-CF и SVD — на уровне случайного ≈ 1 %); гибрид с 1–2 слотами для новинок почти не теряет общее качество.
* **Холодный старт пользователей:** уже 1–2 оценок достаточно для рабочих рекомендаций (nDCG@10 ≈ 0.19) — нужен онбординг.
* Негативный контроль (профили пользователей перемешаны) сводит качество к уровню случайного → утечки данных нет.

## Особенности данных, которые учтены

* В этой версии `books.csv` колонка `id` (1…10000) — это ключ `ratings.book_id`, а `book_id` — Goodreads-ID для `book_tags.goodreads_book_id`; связь проверена по корреляции средних оценок (0.88 против ≈ 0).
* В `ratings.csv` 2278 повторных оценок пары (user, book) — удалены (иначе утечка между train и test).
* Нет временной метки → случайный per-user hold-out вместо временного сплита.
* Выборка ограничена ≈ 100 оценками на книгу → смещение популярности внутри выборки сглажено.
